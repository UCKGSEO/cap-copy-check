CAP COPY CHECK — STANDALONE WEBSITE

The Runable file preview is not the running website. Download the HTML or ZIP
and open it outside Runable. No Runable wrapper or analytics is included.

OPEN ON YOUR COMPUTER
1. Download and unzip cap-copy-check-site.zip.
2. Double-click index.html to open it in Chrome, Edge, Firefox or Safari.
3. The invented example and its scan results should appear immediately.

Alternatively, download cap-copy-check.html directly and open that file.
Internet access is needed for web fonts and, on first upload, the DOCX/PDF
reader libraries. Scanning pasted text itself runs locally without internet.
File contents and pasted text are not sent to those providers.
Fetch URL makes a request only to the page you enter; many sites block it.
If fetching fails, open the page yourself and paste its text.

HOST ON GITHUB PAGES
Use a NEW repository so you do not overwrite your existing Draft Verifier.

1. Create a GitHub repository called cap-copy-check. Choose Public for the
   simplest GitHub Pages setup. Do not upload confidential drafts or files.
2. In the repository, choose Add file > Upload files. Upload index.html from
   the unzipped download to the repository root, not inside a nested folder.
3. Commit the upload to the main branch.
4. Open Settings > Pages.
5. Under Build and deployment, select Deploy from a branch.
6. Select main and / (root), then Save.
7. After GitHub finishes deployment, open the site link shown on that page.

For the uckgseo account and repository name above, the expected site URL is:
https://uckgseo.github.io/cap-copy-check/

The tool includes no analytics, login, database, automatic AI calls or draft storage.
GitHub and external font/library providers still receive ordinary web
requests; this is not a promise of anonymous hosting or zero server logs.

INTERNAL REVIEW WORKFLOW
Review any Recommend against findings first. Open each finding for its
matched wording and suggested fix, revise the draft, then check it again.
Confirm checklist items against evidence already held. Keep the pre-check
note with the draft and evidence. Before publication, have a person review
the full copy, images and context. Use CAP Copy Advice for borderline
claims and legal advice where needed. A clean scan is not approval.

The rule engine and generated note are unchanged from the supplied source.
The October 2026 source label is not a new independent verification of
every rule. Consult the linked current CAP Code and ASA guidance.

ASK AI FOR A DEEPER READ
1. Scan your copy, then go to step 04, below the pre-check note.
2. Choose Ask Claude, Ask ChatGPT, Ask Copilot, Ask Grok or Ask Gemini.
3. The tool prepares a prompt from the current draft, material type and CAP
   findings. It copies the prompt and opens the provider's website.
4. Paste the prompt in that AI chat and submit it yourself. You may need
   to sign in to the provider. No prompt is included in the website URL.
5. If the clipboard is blocked, the prompt is selected for you: press
   Ctrl+C or Cmd+C. If the new tab is blocked, use the website link below.

Remove personal details and sensitive information before sharing. Pasting
and submitting the prompt sends that content to the provider under its
terms and privacy settings. No API keys are needed. The tool does not
receive, store or display the AI's answer; read it in the provider's chat.
An AI-assisted review is not approval from CAP, the ASA or a lawyer.

UPDATING AN EXISTING GITHUB PAGES DEPLOYMENT
Replace the repository's previous index.html with the new index.html
from this ZIP and commit it. Once redeployed, refresh the site. If the
old version persists, use a hard refresh (Ctrl+Shift+R or Cmd+Shift+R).

CHECK THE DEPLOYMENT
- The title should read CAP Copy Check.
- The invented example should say Recommend changes before use.
- On phones, finding cards start collapsed. Tap a card to read its full
  matched wording, rules and suggested fixes. Desktop high-risk cards
  still start open. File and AI privacy help can be expanded on any screen.
- Try switching between light and dark mode.
- Try a .txt, .md, .docx or text-based .pdf upload.
- Check my copy should refresh findings and the pre-check note.
- Download as .txt should download the generated note.
- Each Ask AI button should prepare a prompt and open the chosen website.

This is an automated phrase scan, not CAP, ASA or legal approval.
